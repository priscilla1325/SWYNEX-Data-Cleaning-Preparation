# Customer Data Cleaning Project

## Project Overview
This project focuses on cleaning and preprocessing a customer dataset using Microsoft Excel to improve data quality and consistency.

## Tools Used
- Microsoft Excel

## Dataset
Customer dataset containing customer details, email addresses, country, segment, spending information, signup dates, and active status.

## Data Cleaning Steps

1. **Duplicate Removal:** Removed duplicate records.
2. **Country Standardization:** Standardized country names.
3. **Segment Standardization:** Standardized Enterprise, Consumer, and SMB values.
4. **Missing Spend Values:** Handled missing values using median imputation.
5. **Date Formatting:** Standardized signup dates into YYYY-MM-DD format.
6. **Missing Email Values:** Identified and handled missing email entries.
7. **Active Status:** Checked Yes/No values for consistency.
8. **Name Standardization:** Converted names into proper case and removed extra spaces.

## Outcome
Improved dataset consistency, readability, and quality through Excel-based data cleaning.

## Conclusion
This project provided practical experience in identifying and handling missing values, duplicates, inconsistent formats, and data standardization using Microsoft Excel.
